# 前后端联系

前端三大框架是vue,react,angular.

## 概念

前端和后端之间进行数据交互和通信。在Web开发中，前端负责展示数据和用户交互，后端负责处理业务逻辑和数据存储。为实现前后端的数据交互和通信，要使用一些通信方式和协议。

## 常见的前后端连接方式

### 前后端不分离

- Ajax,基于javascript向后端发送http请求并接收响应。Ajax可以实现<span style="color:red">异步通信</span>，可以在后台与服务器进行数据交互。
- Axios.js,基于promise的http客户端库，可用于发送http请求。它可以在<span style="color:red">浏览器和Node.js环境</span>中使用，提供简洁的API和丰富的功能，如请求拦截、响应拦截、取消请求等。
- Fetch API,浏览器原生提供的一组用于发送HTTP请求的API。它支持<span style="color:red">异步通信</span>，能提供简洁的方式发送请求并返回promise对象。
- 还有websocket,RESTful API.

### 前后端分离

可提升开发效率，增强代码可维护性、支持多终端服务化架构。

### API

前后端开发即使分离，其之间也应当具有协作，即前端返回的 HTML 中嵌入的 JavaScript 如何以何种规范向后端请求数据。而这种规范是需要在开发时确定的，这种规范一般称为 API规范。

#### HTTP请求

请求数据会使用http协议。

前端服务器
     ↓
返回 HTML / JS / CSS
     ↓
浏览器运行 Vue/React
     ↓
向后端 API 服务器请求数据

## 用python实现前端输入->后端返回

### socket

数据转变流程：客户端输入的信息传给浏览器，浏览器发送<span style="color:red">http请求</span>给python后端，后端处理数据得到返回内容，再通过<span style="color:red">http响应</span>传给浏览器，最后浏览器显示结果。

前后端构建流程：

**Python->浏览器：** 创建服务器->创建（可供网络通讯的）服务器通讯对象->为服务器绑定IP和端口->监听客户端连接->等待浏览器连接->当浏览器访问网址，后端就能接收到连接。



python的socket是底层网络通信工具，是程序进行网络通信的接口（浏览器和python程序通过socket进行通信）。可使用`import socket`创建服务器。

> Python
>  ↓
> socket
>  ↓
> TCP
>  ↓
> 自己解析 HTTP
>  ↓
> 自己生成 HTTP 响应

#### Python返回网页（socket）

```python
import socket
server=socket.socket()						/#创建对象
server.bind(("127.0.0.1", 8000))			#绑定IP和端口
server.listen()						#开始监听，搜寻连接口（等待请求）
print("服务器启动：http://127.0.0.1:8000")

while True:									#接收请求
    client, address = server.accept()		#服务器等待连接（客户端）
    request = client.recv(4096)				#从浏览器接收数据
    print(request.decode())
    response = """
HTTP/1.1 200 OK								#浏览器期待http响应
Content-Type: text/html; charset=utf-8

<html>
    <body>
        <h1>Hello Python</h1>
    </body>
</html>
"""

    client.send(response.encode())			
    client.close()							//结束
```

在bash里输入 python server.py ,浏览器访问网址（http://127.0.0.1:8000）就能看到html里的文字Hello Python。

#### 前端输入 传到后端

创建一个输入框，点击提交。

```html
<form method="GET" action="/hello">
    <input type="text" name="name">
    <button type="submit">提交</button>
</form>
```

浏览器发送请求`GET /hello?name=张三 HTTP/1.1`。Python的`request.decode()`得到请求，就能<span style="color:red">解析URL</span>了。

Python自带模块`urllib`处理URL/网络相关功能，`socket`处理网络通信，`json`处理JSON数据。

`urllib.parse`能解析数据，`parse_qs()` 用来解析 URL 中的查询参数。*(query string查询字符串)*

```python
from urllib.parse import urlparse, parse_qs
url = urlparse("/hello?name=张三")
params = parse_qs(url.query)				//解析成参数字典
name = params["name"][0]
result = "你好，" + name + "！"
```

> parse把查询参数转换成`{ "name": ["张三"]}`

输入值->html->浏览器请求->python 接收（recv）->解析参数，得出结果result->生成HTTP返回输出句：你好，张三！并展示到浏览器上。



get数据通常放在URL查询参数，post数据通常放在HTTP请求体。

### HTTPServer

HTTPServer是对 socket 的封装，专门用来处理HTTP协议.

它创建并监听HTTP套接字，并将请求分派给处理程序。

```
def run(server_class=HTTPServer, handler_class=BaseHTTPRequestHandler):
    server_address = ('', 8000)
    httpd = server_class(server_address, handler_class)
    httpd.serve_forever()
```

**创建方法**：

1，在命令行运行命令，直接搭建http服务器；

2，编写自己的脚本并自定义http服务器。

##### 在python代码中实现

格式：HTTP 请求解析 → 路由分发 → 动态拼接响应。

> Python
>  ↓
> HTTPServer
>  ↓
> socket
>  ↓
> TCP

```python
from http.server import HTTPServer, BaseHTTPRequestHandler#HTTP请求处理程序
from urllib.parse import urlparse, parse_qs

class MyHandler(BaseHTTPRequestHandler):#继承HTTP请求处理程序
    # 1. 处理 GET 请求（如何响应）
    def do_GET(self):
        parsed = urlparse(self.path)          # 解析路径和参数
        path = parsed.path
        
        # 2. 路由分发：根据路径返回不同内容
        if path == "/hello":
            # 后端接收参数并处理
            params = parse_qs(parsed.query)
            name = params.get("name", ["世界"])[0]  # 默认值防止空输入
            body = f"<h1>你好，{name}！</h1><a href='/'>返回</a>"
        else:
            # 前端输入界面（表单）
            body = """
            <form method="GET" action="/hello">
                <input type="text" name="name" placeholder="输入你的名字">
                <button type="submit">提交</button>
            </form>
            """
        
        # 3. HTTP 响应（状态行 + 头部 + 空行 + 正文）
        self.send_response(200)
        self.send_header("Content-Type", "text/html; charset=utf-8")#定义响应头
        self.end_headers()                    
        self.wfile.write(body.encode("utf-8"))
# self.wfile.write(bytes("<html><body><h1>hello！</h1></body></html>",utf-8"))
# 4. 启动服务
if __name__ == "__main__":
    server = HTTPServer(("127.0.0.1", 8000), MyHandler)
    print("服务器启动：http://127.0.0.1:8000")
    server.serve_forever()
```

#### 分离

python服务器主要承担两个角色：静态资源服务和接口服务器（API）。

静态资源服务体现在，当浏览器发送地址，服务器需要根据地址返回本地对应文件（eg:index.html）;

API接口体现在，例如当js发送`GET /api/hello?name=张三`给服务器，收到`/api/hello?name=张三`时python应当将name=张三对应到相符的response并返回json`{"message":"你好,张三!"}`。

所以在定义的类MyHandler里必须同时具有api处理数据和能处理静态文件返回网页的功能。

```python
from http.server import BaseHTTPRequestHandler,HTTPServer

class MyHandler(BaseHTTPRequestHandler):
    def do_GET(self):
        if 请求是API:
            返回数据
        elif 请求是文件:
            返回文件
        else:
            404
server = HTTPServer(
    ("localhost",8000),
    MyHandler
)
server.serve_forever()
```

#### CORS跨域资源共享

如果两个URL的协议、端口、主机都相同，则它们同源。同源策略限制由一个源加载的文档/脚本和另一个源的资源进行交互，进而隔绝恶意文档。

CORS（跨域资源共享）允许服务器通过 HTTP 响应头告诉浏览器，哪些 Origin 可以进行跨源访问，以及浏览器是否可以将跨源响应交给当前网页的 JavaScript 读取。

**工作原理**：服务器在 HTTP 响应中添加 CORS 响应头，告诉浏览器哪些 Origin 可以访问该服务器的跨源资源，以及允许使用哪些方法和请求头。另外，对于可能对服务器数据造成副作用的 HTTP 请求方法，该规范要求浏览器对请求进行“预检”。

**简单请求**——满足特定条件的 GET、HEAD、POST 请求，可以直接发送，不需要 CORS 预检。

eg:python服务器的网址在http://127.0.0.1:8000运行，而vue网页在http://localhost:5173。

<span style="color:red">vue网页要得到python的数据，通过`fetch()`发送给浏览器。浏览器发送HTTP请求给python，得到响应后浏览器检查CORS响应头，返回vue js。</span>

js中，用fetch抓取输入内容对应的数据

```js
const response = await fetch(
        `http://127.0.0.1:8000/api/users?q=${userName.value}`
    );//比如，输入框输入Alice
```

浏览器发送

```js
GET /api/users?q=Alice HTTP/1.1
Host: 127.0.0.1:8000
Origin: http://localhost:5173
//提示python该请求由http://localhost:5173发送。
```

python进行响应，找到Alice对应数据并转化为JSON。

浏览器检查CORS响应头。

- 哪些源可以访问我？`*`：任意源。

	```python
	self.send_header('Access-Control-		Allow-Origin', '*')
	```

- 跨域请求允许使用哪些 HTTP 方法？

	```python
	self.send_header(
	    'Access-Control-Allow-Methods',
	    'GET, POST, DELETE, OPTIONS'
	)
	```

**预检请求**——(OPTIONS)询问服务器是否允许此类跨域请求。

例如，此处定义输入内容之后的返回操作。vue抓取method,headers,body，从端口5173向python（指定端口8000）发送请求，要求浏览器对POST进行响应。

```js
const response = await fetch(
    'http://127.0.0.1:8000/api/users',
    {
        method: 'POST',
        headers: {
            'Content-Type': 'application/json'
        },
        body: JSON.stringify({
            id: newId.value,
            name: newUser.value,
            email: newEmail.value
        })
    }
);
```

浏览器开始预检

```http
OPTIONS /api/users HTTP/1.1
Origin: http://localhost:5173
Access-Control-Request-Method: POST
Access-Control-Request-Headers: content-type
```

`do_OPTIONS()` 返回 CORS 响应头，分别告诉浏览器允许的 Origin、HTTP 方法以及请求头。浏览器检查这些信息后，如果预检通过，才会发送真正的 POST 请求。
